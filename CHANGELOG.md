# Changelog

## [1.0.0] - 2024-09-09

### Added
- Initial release of Donanım Hesaplama Sistemi Flutter app
- Çift Açılım (Dual Swing) system calculation
- Çift Açılım Tek Kanat (Single Leaf) calculation mode
- Çift Açılım Çift Kanat (Dual Leaf) calculation mode  
- Tek Açılım (Single Swing) calculation mode
- Material Design 3 UI
- Dark mode support
- System selection screen with 6 categories
- Product detail screen with images
- Calculation results with product tables
- Provider-based state management
- Responsive design for all screen sizes
- Turkish language support

### Features (Implemented)
- ✅ Hardware calculation algorithms

- ✅ Three calculation modes

- ✅ Dark/Light mode
- ✅ Responsive layout
- ✅ Product images display
- ✅ Calculation results export ready
